# 5. PTZ, свет и свойства камеры

[Оглавление](../README.md) · [Границы проверки](08-validation.md)

| Операция | Метод и params |
|---|---|
| Читать свойства | `0x30300`, `{"dplist":[DPID,...]}` |
| Записать свойства | `0x30302`, `{"dplist":[{"dpid":DPID,"value":VALUE}]}` |
| Поворот/STOP | `0x30308`, `{"daid":393728,"vsbmp":1,"in":{"op":OP,"cnt":1}}` |

`PTZ=0x60200`; OP: 0 stop, 1 left, 2 right, 3 up, 4 down. Рассмотренный клиент посылает
STOP через 0,5 с после короткого шага. Нельзя гарантировать доставку STOP при
разрыве сети; непрерывное вращение здесь не используется.

| Свойство | DPID | Значения |
|---|---:|---|
| Белый свет | `0x50100` | auto=0, on=1, off=2 |
| Ночное видение | `0x80105` | auto=0, on=2, off=1 |
| SD status | `0x20100` | 1 NORMAL; 2 abnormal R/W; 5 no card |
| SD capacity | `0x20101` | Строка `общий\|свободно\|занято` |
| SD format state | `0x20102` | Числовой статус; смысл всех отрицательных кодов не установлен |
| Record mode | `0x20103` | Биты: bit0 постоянная, bit1 события, bit3 time-lapse |
| Record quality | `0x20104` | Качество камеры, не CRF сервера |
| Record audio | `0x20105` | boolean |
| Record loop | `0x20106` | boolean циклической перезаписи |

Ёмкость используется как получена от прошивки; при сравнении важен порядок
полей и изменение занятого объёма. Точная единица/расчёт номинальной ёмкости
для других прошивок требуют проверки.

Здесь описаны обращения к камере через IOTC. Номера методов и свойства
не являются HTTP API какого-либо сайта.

Низкоуровневые ACTION `DAID_SD_FORMAT=0x20200` и `DAID_BASIC_REBOOT=0x10202`
встречаются в исходном клиенте, но команды форматирования/перезагрузки не входят
в практический маршрут этого руководства. Отказ авторизации не исправляют
форматированием SD-карты.


## Разделяйте уровни запроса

Для поворота влево внутренний `params` имеет вид:

```json
{"daid":393728,"vsbmp":1,"in":{"op":1,"cnt":1}}
```

Он помещается в JSON-конверт `id / chn / method_id / ts / params` с
`method_id=0x30308`, затем шифруется и упаковывается в IOTC.
Через короткий интервал посылается новый ACTION с `op=0` (STOP).
`daid` и `method_id` — разные поля; `0x60200` равно 393728.

Для включения белого света в `params` передаётся:

```json
{"dplist":[{"dpid":327936,"value":1}]}
```

Здесь 327936 — десятичное представление `0x50100`, метод — `0x30302`.
Не применяйте к ночному видению ту же таблицу значений: у него on=2, off=1.

## Подтверждение результата

Сопоставляйте request ID, method и ответ `result.code`. Успешная запись в
сокет не доказывает выполнения поворота или смены света. Когда свойство
доступно для чтения, проверьте его отдельным READ. Точную структуру ответа
на неизвестной прошивке выясняйте по обезличенному обмену, а не угадывайте.

Короткий шаг и STOP ограничивают движение, но при потере соединения доставка
STOP не гарантирована. Не зацикливайте команды поворота при отсутствии подтверждения.
